# demoblaze-automation-framework

## Project Overview:

Selenium Automation Framework for Demoblaze E-Commerce Application.

## Tech Stack:
1. Java
2. Selenium WebDriver
3. TestNG
4. Apache POI
5. Maven
6. Git

## Framework Design:
Page Object Model
Data Driven Testing
Explicit Waits
Reusable Base Class

## Test Scenarios:
User Sign Up
User Login
Add Product To Cart
Place Order
