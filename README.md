# demoblaze-automation-framework

## Project Overview:

Selenium Automation Framework for Demoblaze E-Commerce Application.

## Tech Stack:
1. Java
2. Selenium WebDriver
3. TestNG
4. Apache POI
5. Maven
6. Git

## Framework Design:
1. Page Object Model
2. Data Driven Testing
3. Explicit Waits
4. Reusable Base Class

## Test Scenarios:
1. User Sign Up
2. User Login
3. Add Product To Cart
4. Place Order
